# Robot Simulation Visualization

This program was designed to visualize the [Robot Simulation](https://github.com/The-codeMachine/RobotSimulation) library. This was built with HTML, CSS, and TypeScript. 

Robot Simulation Visualization uses Robot Simulation's port forwarding change sink to sync with updates. We expect an up-to-date `World` file to be loaded into this program before updates start, or before listening.
